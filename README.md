FitBod

FitBod is a workout tracking web application where users can explore workouts, save their favorite workouts, and create their own workout plan.

Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* JavaScript
* REST API

Features

1. Browse different workouts.
2. View detailed information about each workout.
3. Add workouts to My Plan.
4. Save workouts for later.
5. Remove workouts from My Plan or Saved.
6. Mark workouts as completed.
7. Sort workouts by duration, calories, or name.
8. Show workout statistics like exercises, minutes, and calories.
9. Responsive design for mobile and desktop.
10. Toast notifications for user actions.
